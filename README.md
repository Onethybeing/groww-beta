# GROW Beta

A concept demo of beginner investing features (learn, practise, start small, build the habit, share) built into a
Groww-style app for Indian Gen Z first-time investors.

**Not affiliated with Groww. Demo money only. Prices are real past data as of early Oct 2026.**
